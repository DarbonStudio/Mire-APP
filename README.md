# Mire App

Projet d'application Mire — Entraînement et analyse de performance athlétique.

## Structure du projet

- `AGENTS.md` : Règles maîtresses de l'agent de développement et directives du projet.
- `.agents/rules/` : Règles modulaires (UX & ergonomie, User Flow & prototypage, Design System & Figma).
- `Maquette/` : Éléments graphiques et maquettes de l'application.
